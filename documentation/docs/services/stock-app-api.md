# stock-app API

The contract below is `stock-app/openapi.yaml` itself, pulled into this site at
build time — the same file the service generates its models from and serves at
`/openapi.json`. Nothing here is a second description of the API.

For how the contract is authored, generated from and enforced, see
[stock-app](stock-app.md#http-api). For the endpoints in a running cluster,
with a "Try it out" button that actually calls them, use
http://stock.localhost/docs.
