Your cluster, explained while it runs

A three-node Kubernetes cluster on your laptop: a real stock-price service with its database and UI, one Gateway for all traffic, secrets in Vault, and Prometheus, Grafana and tracing watching it all. Every diagram on this site is drawn from the running cluster, so what you read is what is there right now.

Architecture

How it all fits together

Boxes are workloads, grouped and coloured by namespace; the dot is their readiness. Lines are what the cluster itself says connects them: HTTPRoutes, Service addresses in environment variables, Prometheus annotations and RBAC bindings. Moving dashes are real traffic, measured by Prometheus. Select a box to see its live details.

Requests: the data plane

What your browser and the apps send each other. Every request from outside enters through one Envoy proxy; inside the cluster, pods call Services by DNS name.

Telemetry

What the cluster says about itself. Prometheus pulls metrics from every annotated Service; stock-app pushes traces to the OpenTelemetry Collector, which forwards them to Tempo.

Control plane

Who watches the Kubernetes API. Controllers turn objects into running config: Envoy Gateway turns HTTPRoutes into Envoy routes, and this site turns pods into these diagrams.

Make it move. Open traffic-generator, pick Get bars, send 50 requests and watch the Requests layer: Envoy → stock-app speeds up, then stock-app → TimescaleDB. Switch to Telemetry to see the same requests leave as spans.

Get going

Run it

You need Docker, kind v0.33 (it creates Kubernetes 1.37 nodes, as in CI) and kubectl. Go 1.26, Node.js 24 and Python 3.14 are only needed to change the code.

Delete and recreate the cluster with every component. Safe to re-run.

./recreate-cluster.sh

The same, but stock-app generates its prices instead of calling Yahoo Finance: works offline, and it is what CI runs.

STOCK_PROVIDER=synthetic ./recreate-cluster.sh

It builds the four local images, deploys everything and waits until every *.localhost URL answers; Build & ship shows each step. *.localhost resolves to 127.0.0.1 on macOS and most Linux systems, so there is no DNS to set up.
